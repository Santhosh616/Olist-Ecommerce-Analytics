# Olist E-Commerce Customer & Product Analytics

## Project Overview
This project analyzes Brazilian e-commerce data from Olist to understand sales performance, order trends, customer behavior, and product category performance.

The analysis uses SQL and Python for data exploration and Power BI to build an interactive dashboard.

## Tools & Technologies
- Power BI
- MySQL
- SQL
- Python

## Dataset
The project uses the Brazilian E-Commerce Public Dataset by Olist.

The dataset contains information about customers, orders, products, payments, sellers, and reviews.

## Key Business Insights
- Analyzed approximately 99,000 orders and 112,000 order-item records.
- Identified an overall delivery rate of approximately 97%.
- Found that repeat customers account for approximately 3.12% of unique customers.
- Identified Health & Beauty as one of the highest-revenue product categories.
- Examined monthly sales trends and customer distribution across Brazilian states.

## Power BI Dashboard
The interactive dashboard includes:
- Total Orders
- Total Item Sales
- Delivered Orders
- Delivery Rate
- Monthly Sales Trend
- Order Status Distribution
- Top 10 Product Categories
- Top 10 Customer States

## Project Structure
- `Dashboard/` – Power BI dashboard file
- `SQL/` – SQL analysis queries
- `Python/` – Python analysis scripts
- `Images/` – Dashboard screenshots
- `Dataset/` – Dataset source information

## Project Objective
To use data analytics and visualization techniques to convert raw e-commerce data into meaningful business insights that support better decision-making.
